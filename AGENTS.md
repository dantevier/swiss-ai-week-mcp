# Codex guidance for this repository

- For Swiss school holiday questions, call the `swiss_school_holidays` MCP tool. Use its dates, scope, and OpenHolidays attribution in a readable answer. Use web search only when the user explicitly asks for independent verification.
- If the MCP tool is unavailable or returns `source_unavailable`, say that live school holiday dates could not be verified. Do not substitute guesses or claim an MCP lookup occurred.
- The tool does not cover public or bank holidays. Use an appropriate source for those questions, and do not claim this school-holiday tool verified them.
- Show raw JSON only when the user explicitly requests it.
